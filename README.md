# Student Management System (Swift)

## How to Run
1. Open Xcode
2. Create a Swift Console App OR Swift Playground
3. Paste code into main.swift
4. Run ▶️

## Features
- CRUD operations on students
- Sorting & filtering using closures
- OOP with struct, class, and protocol
- Input validation & error handling
- BONUS: JSON persistence

## Requirements
- Swift 5+
- macOS
